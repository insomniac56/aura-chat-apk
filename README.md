# Aura Chat for Android

Public installer download. Anyone can install it and use it on their own internet — no PC or local server needed.

## Install

1. Download **Aura-Chat.apk** from the [latest release](https://github.com/insomniac56/aura-chat-apk/releases/latest).
2. On your phone, allow installs from unknown sources (your browser or file manager will prompt).
3. Open the downloaded APK and install.
4. Sign in with Google. Chat, media and calls run on cloud services over your own mobile data or Wi-Fi.
